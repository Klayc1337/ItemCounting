# Техническое задание: Система «Товарный Учет»

## 1. Цель проекта

Разработать REST API для ведения складского учета. Система должна обеспечивать:

- создание товаров;
- приемку товаров на склад (приходная накладная);
- отгрузку товаров в магазин (расходная накладная);
- контроль актуальных остатков.

---

## 2. Общее описание

Система состоит из двух логических модулей (в рамках одного монолита с четким разделением слоёв):

- **Складской модуль** — отвечает за товары и их количество.
- **Торговый модуль** — отвечает за заказы магазинов.

**Ключевое правило:** списание товара происходит **только** на основе созданной и подтвержденной накладной.

---

## 3. Функциональные требования (API Endpoints)

### 3.1. Справочник «Товары» (CRUD)

Самый простой CRUD без сложных полей.

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/api/v1/products` | Создать товар (наименование, артикул, единица измерения) |
| `GET` | `/api/v1/products` | Список товаров (с пагинацией) |
| `GET` | `/api/v1/products/{id}` | Получить товар по ID |
| `PUT` | `/api/v1/products/{id}` | Изменить цену или название |
| `DELETE` | `/api/v1/products/{id}` | Удалить (мягкое удаление, если есть движения) |

**Пример тела запроса при создании:**

```json
{
  "name": "Мыло хозяйственное",
  "sku": "SOAP-001",
  "unit": "шт"
}
