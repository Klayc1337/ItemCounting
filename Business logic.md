## При создании Приходной накладной
1. Открыть транзакцию.

2. Сохранить накладную и строки.

3. Для каждой позиции выполнить:

```sql
UPDATE Stock SET quantity = quantity + X WHERE product_id = Y;
```

4. Если записи в Stock для данного товара нет — создать её (INSERT).

5. Закоммитить транзакцию.


## При создании Расходной накладной

1. Открыть транзакцию.

2. Для каждой позиции выполнить блокирующий запрос:

```sql
SELECT quantity FROM Stock WHERE product_id = Y FOR UPDATE;
```

3. Проверить: quantity >= requested.
   - Если да — выполнить UPDATE Stock SET quantity = quantity - X.
   - Если нет — выполнить ROLLBACK и вернуть ошибку с кодом 400.

4. Закоммитить транзакцию.
